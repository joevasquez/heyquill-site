# heyquill.ai

Marketing site for [Quill](https://github.com/joevasquez/Quill) — a voice agent for macOS and iOS.

Static site, deployed via Cloudflare Pages. No build step, no dependencies.

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080. `app.js` is an ES module, so it must be served
over HTTP — opening `index.html` from the filesystem will fail on CORS.

## Deploy

Connected to Cloudflare Pages; pushes to `main` deploy automatically.

```bash
npx wrangler pages deploy . --project-name=heyquill-site
```

## The owl

`assets/quill-owl-sprite.js` is shipped **verbatim** from the Quill design
handoff (`design_handoff_quill_owl_avatar`). It is not a drawing of the owl —
it *is* the owl; every pixel is generated by that file, and there are no image
assets. The same file is ported literally to Swift in the app as
`QuillOwlSprite.swift`.

Don't hand-edit it or "clean it up". If the owl needs to change, it changes in
the handoff and both ports follow. Two rules the renderer depends on:

- `px` (canvas pixels per sprite pixel) **must be a whole integer**, or the art
  shimmers. `app.js` derives the CSS size from `px` rather than the other way
  round, for exactly this reason.
- The animation clock is **never reset on a mode change**. Each state loops on
  its own period, so one shared clock is what makes the cut read as the owl
  simply changing what it's doing.

## Theme

The toggle in the nav cycles **Auto → Light → Dark**, matching the app's
Appearance setting. The preference is stored in `localStorage` under
`quill-theme`; the resolved value is stamped on `<html data-theme>` by a small
**inline, blocking script in `<head>`** — it has to be inline, or the browser
paints light first and dark-mode users get a white flash on every navigation.
That script is duplicated in `index.html` and `privacy.html`; keep them in sync.

All dark values live in one `:root[data-theme="dark"]` block in `styles.css`,
so there's nothing to keep in sync per theme. With JS disabled the page renders
light.

## Colour

The mode palette in `styles.css` and the hex values in `app.js` are the app's
own, from `HexCore/Sources/HexCore/Models/QuillDesign.swift`:

| Mode | OKLCH | sRGB |
|---|---|---|
| Auto (also the brand hue) | `0.72 0.15 292` | `#a791fa` |
| Dictate | `0.74 0.16 248` | `#4ab1ff` |
| Edit | `0.80 0.15 70` | `#faab3f` |
| Act | `0.78 0.13 188` | `#25d2c7` |
| Resolved | `0.80 0.15 150` | `#6ed889` |

If they change in the app, change them here too — mode-as-colour is something
the app actively teaches, and the site should not contradict it.
